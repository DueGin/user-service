# User Service API Contract

## Public Pages

Base URL:

```text
{USER_SERVICE_BASE_URL}
```

Default login page:

```text
GET /auth/login
```

Default register page:

```text
GET /auth/register
```

Both pages preserve these query parameters when switching between login and register:

| Parameter | Required | Notes |
|---|---:|---|
| `app_id` | yes | User Service application id. |
| `redirect_uri` | redirect mode | Business app callback URL. |
| `mode` | optional | `redirect` or `embed`; default is `redirect`. |
| `state` | recommended | Random value generated by business app. |
| `origin` | embed mode | Parent page origin for iframe/popup postMessage. |
| `app_name` | optional | Display name shown on auth pages. |

## Redirect Authorization-Code Flow

Start login:

```text
GET {USER_SERVICE_BASE_URL}/auth/login?app_id={appId}&redirect_uri={callbackUrl}&mode=redirect&state={state}&app_name={appName}
```

User Service callback:

```text
GET {callbackUrl}?code={authorizationCode}&state={state}
```

Exchange code:

```http
POST {USER_SERVICE_BASE_URL}/api/auth/exchange
Content-Type: application/json
```

```json
{
  "code": "{authorizationCode}",
  "appId": "{appId}",
  "apiSecret": "{apiSecret}"
}
```

Successful response:

```json
{
  "success": true,
  "data": {
    "accessToken": "eyJ...",
    "refreshToken": "eyJ...",
    "user": {
      "id": "user_id",
      "username": "zhangsan",
      "email": "user@example.com",
      "phone": null,
      "avatar": null,
      "roles": ["admin"]
    }
  }
}
```

## Session APIs

Get current user:

```http
GET {USER_SERVICE_BASE_URL}/api/auth/me
Authorization: Bearer {accessToken}
```

Refresh token:

```http
POST {USER_SERVICE_BASE_URL}/api/auth/refresh
Content-Type: application/json
```

```json
{
  "refreshToken": "{refreshToken}"
}
```

Logout:

```http
POST {USER_SERVICE_BASE_URL}/api/auth/logout
Authorization: Bearer {accessToken}
```

## Embedded Mode

Login URL:

```text
GET {USER_SERVICE_BASE_URL}/auth/login?app_id={appId}&mode=embed&origin={encodedOrigin}&app_name={appName}
```

Success message:

```ts
{
  type: "AUTH_SUCCESS",
  token: string,
  refreshToken: string,
  user: { id: string; username: string; email?: string }
}
```

Error message:

```ts
{
  type: "AUTH_ERROR",
  error: string
}
```

## Local Demo Defaults

These are for local examples only:

```text
USER_SERVICE_BASE_URL=http://localhost:3000
USER_SERVICE_APP_ID=demo-business-app
USER_SERVICE_API_SECRET=sk_demo_business_app_secret
USER_SERVICE_CALLBACK_URL=http://localhost:3000/api/demo/auth/callback
```

Do not use the demo secret in production.
